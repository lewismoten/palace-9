Training plan and Ollama bridge

Enumerate reachable boards, label each with the minimax teacher, train a 2-layer/32-hidden, eight-expert policy in-browser, export tensors and vocabulary (a–i), then convert the export through a compatible Llama-style Hugging Face checkpoint to GGUF before ollama create. This repository preserves that boundary rather than disguising a prompt wrapper as a trained custom model.

The current host lacks PyTorch and safetensors, which the installed GGUF converter requires. No Ollama model was created yet.
