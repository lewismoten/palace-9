This browser build contains a deterministic minimax teacher and explicit expert labels. It is a training/data-generation lab, not yet a GGUF neural checkpoint; a browser JavaScript model cannot be honestly presented to Ollama until its learned tensors are converted into a supported GGUF architecture.

Complete illustrative 2 × 32 MoE network

Edges are deterministic illustrative initialized weights: thickness and brightness reflect absolute weight value. Lime links show the current selected expert’s route. They are not trained checkpoint tensors.

Training plan and Ollama bridge

Enumerate reachable boards, label each with the minimax teacher, train a 2-layer/32-hidden, eight-expert policy in-browser, export tensors and vocabulary (a–i), then convert the export through a compatible Llama-style Hugging Face checkpoint to GGUF before ollama create. This repository preserves that boundary rather than disguising a prompt wrapper as a trained custom model.

The current host lacks PyTorch and safetensors, which the installed GGUF converter requires. No Ollama model was created yet.
